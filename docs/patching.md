# Patching

Apply JSON-semantic structural changes directly to supported Java object graphs.

## JSON Patch (RFC 6902)

JSON Patch provides an ordered sequence of add, remove, replace, move, copy, and test operations.

## JSON Merge Patch (RFC 7386)

Merge Patch applies object-based changes with its own null/removal semantics.
