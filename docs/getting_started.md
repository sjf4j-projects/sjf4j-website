# Introduction

**SJF4J (Simple JSON Facade for Java)** is a unified structural processing layer built on JSON semantics. It brings binding, navigation, validation, mapping, and patching together across native Java object graphs.

## Why SJF4J?

SJF4J can operate directly on POJOs, Maps, Lists, and other supported models. It exposes consistent semantics across multiple JSON backends and combines flexible runtime execution with compile-time generated APIs.

## How It Fits into Your Stack

SJF4J complements JSON libraries such as Jackson, Gson, Fastjson2, and JSON-P, rather than requiring a new data model for every operation.
