# Schema-to-Java Generator

This is the reserved page for the next-generation Schema-to-Java Generator. The new website does not yet provide an interactive generator.

## Overview

Generate Java model classes from JSON Schema. The implementation will be added and validated against the current SJF4J APIs before this page becomes a working tool.

## Planned Workflow

1. Provide a JSON Schema.
2. Configure package and model options.
3. Preview generated Java source.
4. Download the generated files.

## Supported Features & Limitations

Supported schema constructs and generation limits will be documented here after the new implementation is available.
