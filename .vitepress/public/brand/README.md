# SJF4J Logo Assets

Transparent PNG wordmarks matching the homepage's **SJF4J** branding: Inter ExtraBold, coral first `J` (`#E76F51`), dark text (`#12161C`). All images include the complete five-character wordmark, with no extra icon.

## Horizontal wordmarks

- `sjf4j-wordmark-256x64.png` — compact UI use
- `sjf4j-wordmark-512x128.png` — documentation and headers
- `sjf4j-wordmark-1024x256.png` — README and presentations
- `sjf4j-wordmark-1200x300.png` — high-resolution banners

## Square PNGs

- `sjf4j-square-64x64.png` — compact square asset
- `sjf4j-square-128x128.png` — small avatars
- `sjf4j-square-180x180.png` — Apple touch icon dimensions
- `sjf4j-square-192x192.png` — app icon dimensions
- `sjf4j-square-256x256.png` — medium avatars
- `sjf4j-square-512x512.png` — high-resolution avatars/app icon dimensions

The square assets retain the full wordmark, centered with transparent padding. At very small sizes, prefer the horizontal version or the site's text heading for legibility. These are **source assets only**; no homepage or favicon replacement is implied.
