# SJF4J Logo Assets

Transparent PNG wordmarks matching the homepage's **SJF4J** branding: Inter ExtraBold, coral first `J` (`#E76F51`), dark text (`#12161C`). All images include the complete five-character wordmark, with no extra icon.

## GitHub organization avatar

- `sjf4j-avatar-512x512.png` — **recommended for GitHub profile / organization avatar**. Opaque warm off-white background (`#FFF7F2`) with dark-gray text (`#24292F`) and coral first `J` (`#E76F51`). The wordmark is rendered directly from Inter Display ExtraBold at 4× resolution and downsampled for sharper edges. The letters are larger for better legibility at GitHub's smaller display sizes, centered with padding for the circular crop, and work in light and dark themes. This is an alternate GitHub avatar asset, not a replacement for the website wordmark.

## Square PNGs

- `sjf4j-square-64x64.png` — compact square asset
- `sjf4j-square-128x128.png` — small avatars
- `sjf4j-square-180x180.png` — Apple touch icon dimensions
- `sjf4j-square-192x192.png` — app icon dimensions
- `sjf4j-square-256x256.png` — medium avatars
- `sjf4j-square-512x512.png` — high-resolution avatars/app icon dimensions

The square assets retain the full wordmark, centered with transparent padding. At very small sizes, prefer the horizontal version or the site's text heading for legibility. The images are published from `public/brand`. The 64×64 square serves as the browser favicon, the 180×180 square as the Apple touch icon, and the 512×512 square as the social preview image.
